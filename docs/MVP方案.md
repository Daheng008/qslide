> 2026-10-10 立项 ｜ 一句话定位：**把咨询级排版工作流（QPT 的交互基因）以现代 Office Add-in 形态重做，面向所有做规范演示文稿的人。**
> 姊妹文档：`交互基因清单.md`（235 个交互单元 + 两周频率记录表）

## 1. 与 QPT 的关系（IP 边界，必须遵守）

| 维度 | 做法 |
|---|---|

## 2. 技术架构

```
┌─ Office Add-in（manifest.xml + Web 技术）
│   ├─ Ribbon 按钮（Add-in Commands，XML 定义，一套跑 Win/Mac/Web）
│   ├─ Office.js（PowerPoint API）：文档读写、形状操作、选区
│   └─ Task Pane（React + Vite）：规范检查面板、设置、色板管理
├─ 本地存储：localStorage / Office Settings（个人配置、频率埋点）
└─ （P2）云服务：账号、色彩方案云同步、模板订阅分发
```

**关键技术风险（Phase 0 必须先验证）**：PowerPoint 的 JS API 历史上比 Word/Excel 弱，
形状几何读写、选区操作、版式操作的能力边界直接决定哪些交互基因能落地。
用 Script Lab 花两三天把「基因清单 MVP 候选」逐条做能力探测，产出《能力矩阵》再定 MVP 最终范围。
探测不通的项有两个退路：①等 API 更新（微软在快速补齐）；②Windows 端用 VBA/COM 混合桥接（仅 Win）。

## 3. 阶段计划

| 阶段 | 内容 | 产出 | 周期 |
|---|---|---|---|

## 4. 商业模型（锚点，P3 后再细化）

- **免费**：高频排版操作（贴合对齐、同宽同高等）——获客与日活；
- **付费（年费 99-299 档）**：低频高价值——企业版式规范导入+全稿合规检查报告、色彩方案云同步、模板订阅；
- **企业版**：私有部署 + 自定义规范库（对 B 端客户按席收费）；
- **分发**：AppSource 公开上架 + 企业管理员 sideload（规避审核周期）。

## 5. 竞争差异化

| 对手 | 它的路线 | QSlide 的差异 |
|---|---|---|
| PowerPoint Designer | AI 生成整页设计 | 不做生成，做**操作与规范**（互补不冲突） |
| iSlide | 模板/素材库 | 不做素材，做**排版动作** |
| think-cell | 咨询图表 | 不做图表，做**页面排版** |
| QPT 本体 | VBA，Win 专用，无中文 | 同款交互 + 三平台 + 中文 + 现代 UI |

## 6. 成功标准（P2 结束时）

1. 内测用户周活跃 ≥ 3 天/人；
2. 「贴合对齐」等 MVP 功能人均周使用 ≥ 10 次；
3. ≥ 1 个团队愿意为规范检查付费或写采购建议；
4. 未达 → 止损，经验沉淀回 Enniu 产品线。
