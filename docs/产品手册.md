# QSlide 产品手册

> 咨询级 PPT 排版工具 · v1.0.0.3 · 2026-10-18

QSlide 是一套 PowerPoint 加载项：在功能区新增 **QSlide 标签页**（9 组 50 个按钮），配合右侧任务面板，覆盖咨询顾问做 PPT 最高频的排版动作。所有操作**点击即生效**：成功不打扰，结果与提示统一显示在右侧面板的「反馈与提示」区。

---

## 1. 安装（macOS）

```bash
cd QSlide 项目目录
bash install-sideload.command      # 自动：启动本地服务 + 安装加载项 + 信任证书
```

然后 **Cmd+Q 完全退出 PowerPoint，重新打开**。功能区出现「QSlide」标签页即安装成功。

> 常见情况：某天打开 PowerPoint 发现 QSlide 不见了——这是 Office 清理了加载项目录，重跑一次上面的命令即可。

## 2. 功能区 9 组按钮（对照 QPT 按主题归组）

## 3. 右侧任务面板（点「QSlide」打开）

- **反馈与提示**：所有 Ribbon 操作的结果日志（成功/失败/原因），置顶显示——找「为什么没反应」先看这里；
- **排版体检**：一键扫描本页 / 全文档，输出问题清单（字号、对齐、边距、色系等），支持「一键合规」自动修复；
- **取色器 + 我的色板**：吸取任意形状颜色存入色板，跨页复用；
- **标注与生成**：文本拆形状（Lines2Shapes）、Roadmap 页眉、便签、单位标注、自动换行开关；
- **思维模型**：2×2 矩阵、金字塔，一键生成可编辑的基础版式；
- **色板 / 配色方案 / 频率表**：咨询风格组件速查。

## 4. 交互原则

1. **直接作用**：点按钮立即改图元，不弹确认框；
2. **反馈进面板**：成功静默（图元变化即反馈），失败写进面板日志并给出原因与补救建议；
3. **诚实降级**：你的 PowerPoint 版本不支持某 API 时，面板会明确说明需要什么版本，而不是假装成功。

## 5. FAQ

**Q：点按钮没反应？**
先看面板「反馈与提示」——多数情况有原因说明（如「请先选中形状」「需 PowerPointApi 1.8+」）。

**Q：QSlide 标签页消失了？**
Office 会不定期清理加载项目录。重跑 `bash install-sideload.command` + Cmd+Q 重启 PowerPoint。

**Q：图标显示为蓝色斜条？**
本地服务没在跑（`https://localhost:3000` 需在线）。重跑安装脚本即可。

**Q：插入图片失败？**
面板会显示具体错误码，反馈给维护者定位；已知部分 macOS 版本对图片 API 支持有限。

**Q：Windows / 网页版能用吗？**
设计上全平台通用，当前主要在 macOS 验证；其他平台如遇行为差异欢迎反馈。
