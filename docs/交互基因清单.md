# QSlide 交互基因清单

> 数据来源：QPT v84 `customUI.xml` 全量提取（真实数据，非凭记忆）——这是 QPT 十年使用沉淀下来的「交互设计基因」。
> 
> **用法**：打印本清单 → 正常做片两周，每次用 QPT 点一个按钮就在「频率」列画一杠（正字）。
> 两周后统计：频率前 10 的功能 = QSlide MVP 范围；频率为 0 的 = 不做。
>
> **初筛建议列**基于 Mac 移植版真机验证结果预填：MVP候选=纯VBA已验证可用；P2=依赖邮件/存储/模板引擎或低频；弃用=Windows专有。
