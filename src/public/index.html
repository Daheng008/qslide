📥 安装步骤（Windows PowerPoint）

先下载 manifest.prod.xml 存到本机（如 D:\QSlide\），再任选下面一种方式：

方法 A · 插入选项卡上传（推荐）

  1. PowerPoint → 「插入」→「获取加载项」（旧版叫「我的加载项」）。
  2. 在窗口中找到 「上传我的加载项」（通常在左下角）。
  3. 选中 manifest.prod.xml → 打开 → 功能区出现 QSlide 选项卡。

方法 B · 受信任目录（无需登录 Microsoft 账户）

  1. 把 manifest.prod.xml 放入一个文件夹，如 D:\QSlide\。
  2. 「文件 → 选项 → 信任中心 → 信任中心设置 → 受信任的加载项目录」。
  3. 「目录 URL」填 D:\QSlide → 添加目录 → 勾选「显示在菜单中」→ 确定。
  4. 完全重启 PowerPoint → 「插入 → 获取加载项」→ 「共享文件夹」标签 → 双击 QSlide。

🏢 企业批量：由 Microsoft 365 管理员在后台「集成应用 → 上传自定义应用」选择该清单并指派给同事，全员自动安装。
