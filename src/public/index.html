📥 安装步骤
  1. 点击上方「下载安装清单」，把 manifest.prod.xml 存到本机。
  2. 打开 Windows 版 PowerPoint →「文件 → 选项 → 加载项」。
  3. 底部「管理」选「自定义加载项」→「转到…」→「添加」→ 选中该文件 → 确定。
  4. 重启 PowerPoint，功能区将出现 QSlide 选项卡，即可使用。

🏢 企业批量：由 Microsoft 365 管理员在后台「集成应用 → 上传自定义应用」选择该清单并指派给同事，全员自动安装。
